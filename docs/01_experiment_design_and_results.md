# 相机随机化训练：完整对比报告

> 2026-11-09 | 单卡 L40 | π0.5 + LoRA（50 M 可训练）

## 一句话结论

**相机随机化把训练轴上的断崖彻底填平了（20° 从 0% → 84%），
但训练轴以外的方向依然完全失效（反向 0%、侧向 2%、垂直 14%）。**

这说明：随机化让模型学会了**这条轴上的视角插值**，而不是真正的视角不变性。
是"有效的工程手段"，但不是"学到的泛化能力"。

## 四个关键发现

### 1. 训练轴上：断崖被彻底填平

```
角度      基线      随机化
 0°       44%  →   90%
 5°       96%  →   82%
10°       18%  →   92%     ← 基线在此崩溃
14°        6%  →   74%
20°        0%  →   84%     ← 基线归零，随机化 84%
25°        0%  →   34%     ← 超出训练范围仍有部分泛化
```

训练时相机覆盖 0–20°，测试的 25° 虽然超出范围，仍从 0% 提升到 34%——
说明模型在训练轴附近形成了**连续的**视角表征，而不是记住 5 个离散位置。

### 2. 训练轴以外：完全无效

```
方向              基线      随机化
反向（往里收）     0%   →    0%
侧向（左右偏）     2%   →    2%
垂直（纯抬高）    14%   →   14%
```

**三个方向一个都没改善。** 这是本实验最重要的负面结论：
随机化只在它覆盖的那个子空间里起作用，对正交方向零迁移。

### 3. 分布内性能大幅提升（意外收获）

```
IND:       51%  →  98%
OOD-颜色:  61%  →  87%
```

随机化不仅没牺牲性能，数值上**接近翻倍**。⚠️ 但这一格混有 FOV（1.1 vs 1.05）与初始化差异
（偏差说明第 3、4 条），只能读方向。原因推测：
多视角数据等效于 5 倍的数据增广，让模型学到了更鲁棒的视觉特征。

### 4. 颜色依然无关

两个模型在 OOD 颜色上都表现良好（61% / 87%），再次确认颜色维度不是瓶颈。

## 对"泛化 vs 记忆"的判断

| 主张 | 证据 | 判断 |
|---|---|---|
| 随机化有效 | 训练轴 20° 从 0%→84% | ✅ 成立 |
| 随机化学到真泛化 | 三个正交方向 0/2/14%，与基线完全相同 | ❌ **不成立** |
| 随机化提升整体性能 | IND 51%→98% | ⚠️ 方向成立，但混有 FOV 与初始化差异 |
| 视角是 VLA 的瓶颈 | 基线 14° 就崩到 6% | ✅ 成立 |

**结论**：相机随机化是有效的**数据增广手段**，但它买到的是"这个轴上的插值能力"，
不是"视角不变性"。真正的视角泛化需要**多轴同时随机化**，甚至需要架构层面的改动
（如 3D 表征、视角等变网络）。

## 录制时的意外发现（未纳入正式结论）

第一次录制用 512×512 渲染（评测协议是 256×256），
基线模型在 0° 下 **5/5 全部失败**；改回 256 后恢复正常（种子 1000 成功，64 步）。

说明该策略对**渲染分辨率**同样敏感——这是比相机扰动更隐蔽的一种分布偏移。

## 后续改进方向

1. **多轴随机化**：同时随机化 3 条轴 → 预测三个方向都会改善（最直接的验证）
2. **更大范围的单轴**：0–40° → 看 25° 的 34% 能否推到 80%
3. **检查是否真的需要 5 档**：2 档 vs 5 档 vs 连续随机，看数据效率
4. **架构层面**：对比带深度输入 / 3D 特征的模型在正交轴上的表现

## 偏差说明

详见 [`04_deviations_and_limitations.md`](04_deviations_and_limitations.md)。四条无法消除的偏差：

1. **单随机种子**（每多一个种子需再训 5.7 小时）
2. **数据量不等**（1000 vs 1200 条，官方演示只有 1000 条轨迹）
3. **FOV 不一致**：基线数据 `fov=1.1`，随机化与评测 `fov=1.05`（D4）
4. **初始化不一致**：基线训练时 base 权重有 3 个块被截断，随机化用的是修复后的完整权重（T3）

第 3、4 条都会落到 `ind` 这一格上：**51% → 98% 只能读方向，不能当成「随机化提升一倍」的结论**。
同样偏差下对照的 20°（0% → 84%）与三条正交轴（0/2/14%，两模型完全相同）不受影响。
